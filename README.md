# 名画クイズ 〜この絵を描いたのは誰？〜

表示された名画を見て、その作者を10人の巨匠から選ぶクイズです。
`index.html` 1ファイルだけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開くだけです。GitHub Pages に置いてもそのまま動きます。

1. 「10問で挑戦」か「全問に挑戦」を選んでスタート
2. 絵画が表示されるので、その下のボタンから作者を選ぶ
3. 正解・不正解と、作品の解説がその場で表示される
4. 最後に正解数・ランク・出題された全作品の一覧が出る

キーボードの **1〜9・0** キーでも回答できます（0 = 10番目の選択肢）。
回答後は **Enter / Space** で次の問題に進みます。

> 絵画の画像は Wikipedia から読み込むため、**インターネット接続が必要**です。

### ピカソ・ウォーホル・ダリ・草間彌生の作品について

この4人の作品は**まだ著作権が存続している**ため、画像を同梱していません。
そのため出題される絵画は上記6人の作品（すべてパブリックドメイン）で、
残る4人は選択肢のダミーとして機能します。

ご自身で用意した画像を使って出題に加えることもできます。`index.html` 内の
`EXTRA_QUESTIONS` に追記してください。

```js
const EXTRA_QUESTIONS = [
  { img:"images/guernica.jpg", title:"ゲルニカ", year:"1937年",
    place:"ソフィア王妃芸術センター（マドリード）",
    artist:"パブロ・ピカソ",
    desc:"スペイン内戦下の空爆を描いた大作。..." },
];
```

- `img` … 画像のURL。`images/xxx.jpg` のようにローカルのパスも指定できます
- `artist` … 上の10人のいずれかと**完全に同じ文字列**を書いてください

## 問題を追加・編集する

`index.html` 内の `QUESTIONS` 配列を編集します。

```js
{ wiki:"The Starry Night",              // 英語版Wikipediaの記事名（ここから画像を自動取得）
  title:"星月夜", year:"1889年",
  place:"ニューヨーク近代美術館（MoMA）",
  artist:"フィンセント・ファン・ゴッホ",
  desc:"サン＝レミの療養院の窓から見た夜明け前の空を..." },
```

画像はファイル名を直接書かず、**記事名から Wikipedia API 経由で解決**しています
（`action=query&prop=pageimages`）。ファイルが差し替えられてもリンク切れになりません。
画像を取得できなかった問題は自動的に出題から外れます。

## 画像の出典

すべて Wikipedia / Wikimedia Commons のパブリックドメイン作品です。
画像は実行時に読み込まれ、このリポジトリには含まれていません。
